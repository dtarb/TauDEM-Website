Retention Limited Flow Accumulation

Title Retention Limited Flow Accumulation

Summary

The Retention Limited Flow Accumulation tool calculates the flow accumulation limited by retention parameters.

Usage

Command Prompt Syntax

mpiexec –n <number of processes> retlimflow -ang <angfile> -wg <wgfile> -rc <rcfile> -qrl <qrlfile>

Parameters

  • angfile: Input D8 pointer grid (integer raster)
  • wgfile: Input weight grid (float raster)
  • rcfile: Input retention coefficient grid (float raster)
  • qrlfile: Output retention limited flow accumulation grid (float raster)

Syntax

RetentionLimitedFlowAccumulation_ (Input_D-Infinity_Flow_Direction_Grid, Input_Weight_Grid, Input_Retention_Capacity_Grid, Number_of_Processes, Output_Retention_Limited_Runoff_Grid)

Parameter Explanation Data Type
Input_D-Infinity_Flow_Direction_Grid Input D-Infinity flow direction grid (float raster) Raster Layer
Input_Weight_Grid Input weight grid (float raster) Raster Layer
Input_Retention_Capacity_Grid Input retention capacity grid (float raster) Raster Layer
Number_of_Processes The number of processes to use for parallel processing Integer
Output_Retention_Limited_Runoff_Grid Output retention limited runoff grid (float raster) Raster Layer
