Height above Nearest Drainage (HAND) Overview

Summary

The HAND (Height Above the Nearest Drainage) tools compute the vertical distance from each cell to the nearest drainage cell and provide rasters useful for flood mapping and hydrologic analysis. HAND rasters are typically derived from a DEM and a stream/drainage raster and can be used to identify low-lying areas relative to channel elevation.

Tools

Tool Description
Create HAND Grid Generates a HAND raster from a digital elevation model (DEM) and an input drainage/stream raster. The output raster contains the vertical distance (height) above the nearest drainage cell for each pixel in the DEM domain. Inputs are resampled to the DEM resolution when necessary.
HAND-based Flood Mapping Uses the HAND raster to derive inundation extents for specified water-level thresholds. This tool converts HAND values into binary inundation maps or depth rasters for simple flood-susceptibility assessments.
